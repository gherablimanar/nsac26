# Master-plan feature coverage

All 19 feature areas remain tracked. This branch contains only a runnable scaffold;
every feature below is pending implementation or integration. Priorities follow the
master plan, including its later what-if proposal.

| Feature | Priority | Planned responsibility |
|---|---|---|
| Core vitals | Must | Browser entry/trends; backend validation and source metadata |
| Ionizing radiation | Must | NASA provider, normalized cache and explicit freshness |
| Bone health | Must | Browser demo trends; evidence and clear measurement limits |
| Muscle/exercise | Should | Browser logs; approved-plan references and evidence |
| Sleep/circadian | Must | Browser logs/debt; context and evidence support |
| Mental health | Must | Mood/stress inputs and human support; privacy decisions required |
| Hydration/renal | Must | Browser coupled pattern; evidence-linked explanation |
| Vision/SANS | Should | Browser self-assessment; source-linked human-review guidance |
| Nutrition | Should | Food/body-mass logs; evidence and source-quality checks |
| Cognition/readiness | Must | Browser timed tests; advisory explanation for human review |
| Medication | Must | Approved schedule references, adherence, storage and expiry |
| AI officer | Must | Optional model orchestration, evidence and deterministic fallback |
| Body map | Must | Browser rendering; shared signal/risk identifiers |
| Mission profiles | Must | Shared ISS/Moon/Mars context and explicit scenario delay |
| Earth link | Should | Draft reports; browser outbox and future approved transport |
| Offline operation | Must | Browser PWA/rules; exportable evidence and action cards |
| Immune strain | Could | Browser demo pattern; symptom/evidence support |
| Crew overview | Could | Multi-crew UI; privacy/access and aggregation contracts |
| What-if simulation | Should | Labelled browser simulation, not validated health prediction |

The planned seven coupling patterns are kidney-stone-related, fluid shift, cognition,
musculoskeletal decline, immune strain, under-fuelling and solar-storm exposure.
They remain browser-owned demo rules until validated and reviewed.

Medication potency forecasting remains a research question: there is no validated
general radiation-to-potency model in this project. Readiness advice does not grant
operational EVA clearance. No personalized medical prediction or treatment efficacy
is established by the synthetic data. These limits are requirements for future work,
not capabilities implemented by creating the folder structure.
